# ABES FSD — Day 0 to Day 11

This archive contains the repository's complete `day_0` through `day_11` folders, kept in separate day-wise directories. Source files and required project assets/configuration are preserved as provided in the uploaded repository archive.

## Contents

- `day_0` to `day_6`: JavaScript, HTML/CSS, and React practice files
- `day_7` and `day_9`: Create React App projects
- `day_8`: React props practice
- `day_10` and `day_11`: Vite + React projects

Open the individual `index.html` files for standalone exercises. For React app folders with a `package.json`, open a terminal in that folder, run `npm install`, then run `npm start` (day_7/day_9) or `npm run dev` (day_10/day_11).

Note: The ZIP intentionally includes only day_0 through day_11; other repository projects are excluded. Files are preserved from the provided repository archive and have not been rewritten without their assignment requirements.
